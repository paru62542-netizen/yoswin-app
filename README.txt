YOSWIN Android app (WebView) - GitHub se APK banta hai

1. site-url.txt me apni Railway site ka poora link likho (sirf ek line), jaise: https://xxxx.up.railway.app
2. Ye saari files (.github folder samet) PUBLIC GitHub repo me upload karo.
3. Repo me Actions tab > "Build YOSWIN APK" > Run workflow. 3-5 minute me APK ban jayegi.
4. APK Releases me yoswin.apk naam se milegi. Seedha download link:
   https://github.com/USERNAME/REPO/releases/latest/download/yoswin.apk
   Ye link Railway Variable LINK_APP me daalo.
